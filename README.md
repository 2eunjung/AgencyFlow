## Overview

**AgencyFlow**는 웹에이전시 PM 업무를 수행하며 경험한 **프로젝트 관리와 사내 연차 관리의 비효율을 개선하기 위해 개발한 업무 관리 시스템**입니다.

여러 시스템과 문서에 분산되어 있던 프로젝트 정보, 일정, 담당자, 고객 소통, 자료 및 작업 이력을 하나의 흐름으로 통합했습니다. <br>
아울러 연차 신청·승인·잔여 연차 확인과 휴가 일정도 함께 관리할 수 있도록 구성했습니다.

역할별 대시보드에서는 납기 지연·임박, 이슈, 완료 승인 대기, 미배정 프로젝트, 수금/오픈 확인 대상을 구분하여 **사용자가 현재 확인하고 처리해야 할 업무를 찾을 수 있도록 설계**했습니다.

## Background

웹에이전시 PM으로 근무하며 프로젝트 현황 파악과 업무 인계 과정에서 **정보가 여러 시스템과 문서에 분산되어 반복 확인 작업이 발생하는 문제**를 경험했습니다.

### 기존 업무 환경

| 구분 | 관리 방식 | 발생한 문제 |
|---|---|---|
| 계약·고객 정보 | 사내 인트라넷 | 정보를 확인할 때마다 페이지를 이동해야 해 업무 흐름이 끊김 |
| 프로젝트 일정 | 인트라넷, 팀별 문서, 파트별 일정표 | 일정 기준이 분산되어 전체 진행 상황을 파악하기 어려움 |
| 고객 소통 | 메신저, 메모, 개별 공유 | 담당자 부재나 변경 시 주요 맥락을 다시 확인해야 함 |
| 작업 완료·승인 | 담당자 간 개별 확인 | 작업 완료와 검수·승인 완료를 구분하기 어려움 |
| 연차·휴가 | 수기 관리, 메신저 상태값 | 잔여 연차와 휴가 일정을 즉시 확인하기 어려움 |

### 문제 정의

> 하나의 프로젝트 상태를 확인하기 위해 여러 시스템과 문서를 오가야 했고, 진행 상황 파악 및 담당자 확인, 일정 점검, 승인 처리, 업무 인계 과정에서 반복적인 확인 작업이 발생했습니다.

### 해결 방향

- **정보 통합:** 프로젝트 정보, 일정, 이슈, 소통내역, 자료 및 작업 이력을 프로젝트 단위로 연결
- **처리 업무 구분:** 납기 지연·임박, 이슈, 승인 대기 등 확인이 필요한 대상을 대시보드에 표시
- **역할별 화면 구성:** PM 팀장, PM, 파트 팀장, 작업자의 업무에 맞게 메뉴와 정보 노출
- **승인 과정 기록:** 담당자 → 팀장 → PM의 단계별 완료 승인과 반려 이력 관리
- **조회 흐름 연결:** 대시보드에서 상세 패널이나 조건별 프로젝트 목록으로 이동

## Design Decisions

### 역할별로 필요한 정보에 집중

모든 사용자에게 동일한 화면을 제공하기보다, 역할별로 확인하고 처리해야 하는 업무를 구분했습니다. <br>
일반 작업자는 일정에 집중하고, PM과 팀장은 관리 대상 및 승인 대기 업무를 확인할 수 있도록 구성했습니다.

### 작업 완료와 승인 완료의 구분

담당자의 작업 종료와 다음 단계로 넘기기 위한 승인 완료를 구분했습니다. <br>
단계별 승인/반려 이력을 남겨 현재 처리 주체와 업무 진행 맥락을 확인할 수 있도록 했습니다.

### 현황 조회와 상세 업무의 연결

대시보드 일정에서는 현재 화면 위에 상세 패널을 열고, 통합데이터에서는 선택한 조건을 프로젝트 목록에 적용하도록 구성했습니다. <br>
현황을 확인한 뒤 상세 내용을 찾기 위해 검색을 반복하는 과정을 줄이는 데 초점을 맞췄습니다.

## Roadmap
현재 AgencyFlow는 **분산된 프로젝트·일정·업무 이력을 통합하고, 역할별 대시보드에서 관리 대상과 처리 대기 업무를 확인**할 수 있도록 구현했습니다.<br>
향후에는 **이슈의 후속 조치, 단계별 지연 원인, 변경요청의 일정·비용 영향을 추적하고 다중 사용자 환경의 저장 안정성을 보완할 계획**입니다.

| 항목 | 개선 방향 |
|---|---|
| **이슈 후속 조치** | 조치 담당자, 처리 목표일, 다음 행동을 기록하여 해결 과정 추적 |
| **단계별 일정 관리** | 단계별 목표일과 지연 사유, 납기 변경 이력 관리 |
| **변경요청 관리** | 계약 범위, 추가 일정·비용, 고객 확인 및 승인 내역 연결 |
| **공정별 대기 시간** | 담당자 작업 구간과 팀장·PM 승인 대기 구간 구분 |
| **리소스 현황** | 작업자별 진행 업무, 가까운 납기, 휴가를 함께 확인 |
| **저장 안정성** | 다중 사용자 환경의 동시 수정 감지 및 충돌 처리 |
