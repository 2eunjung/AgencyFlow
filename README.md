# AgencyFlow
> Web Agency Project Management System

AgencyFlow는 웹에이전시 PM 업무를 수행하며 경험한 프로젝트 관리와 
사내 연차 관리의 비효율을 개선하기 위해 개발한 프로젝트입니다.

프로젝트 진행 현황, 일정, 고객 자료, 업무 이력 등 분산되어 관리되던 정보를 하나의 시스템에서 통합 관리하고, 

연차 신청·승인·잔여 연차 확인까지 함께 처리할 수 있도록 설계하였습니다.

---

## 프로젝트 소개

웹에이전시 PM으로 근무하며 프로젝트 관리에 필요한 정보가 여러 시스템과 문서에 분산되어 있어, 
프로젝트 현황을 파악하거나 업무를 인계하는 데 많은 시간이 소요되는 문제를 경험했습니다.

고객과의 메신저 소통 내역, 영업 메모, 견적서와 같은 계약·고객 정보는 사내 인트라넷에서 확인해야 했고, 
프로젝트 일정은 별도의 일정관리 시스템, 팀별 관리 문서, 각 파트에서 개별적으로 관리하는 일정표 등으로 나뉘어 있었습니다.

이로 인해 하나의 프로젝트 상태를 확인하기 위해 여러 시스템과 문서를 오가야 했고, 
진행 상황 파악, 담당자 확인, 일정 체크, 업무 인계 과정에서 반복적인 확인 작업이 발생했습니다.

또한 사내 연차 관리가 수기 방식으로 이루어져 잔여 연차를 확인하려면 인사 관리 담당자에게 직접 문의해야 하는 불편함도 있었습니다.

AgencyFlow는 이러한 업무 비효율을 개선하기 위해 프로젝트 기본 정보, 고객 자료, 담당자 배정, 일정, 이슈, 작업 이력을 하나의 흐름 안에서 확인하고 관리할 수 있도록 설계했습니다.
아울러 연차 신청, 승인, 잔여 연차 확인까지 하나의 시스템에서 관리할 수 있도록 확장하여, 프로젝트 관리와 근태 관리 업무를 함께 개선하는 것을 목표로 구현했습니다.

## 주요 기능

- 대시보드
- 프로젝트 목록 및 상세 관리
- 프로젝트 담당자 배정 관리
- 프로젝트 완료 승인 및 작업 스택 관리
- 프로젝트 일정 및 일정 히스토리 관리
- 주요 이슈사항 및 소통내역 관리
- 프로젝트 자료실 및 첨부파일 관리
- 연차 신청, 승인, 잔여 연차 관리
- 휴가 일정 캘린더 관리
- 회원, 부서, 권한 관리
- 로그인 로그 및 프로젝트 로그 관리

## 세부 기능

### 프로젝트 관리

- 프로젝트 기본 정보, 계약 정보, 고객 담당자 정보 관리
- 프로젝트 마일스톤 및 작업상태 관리
- 프로젝트별 PM, 디자이너, 퍼블리셔, 프로그래머 담당자 배정
- 담당자 배정 여부에 따른 미배정/배정완료 구분
- 프로젝트별 주요 이슈사항 및 소통내역 관리
- 견적서 등록 및 다운로드
- 다국어 여부, 랜딩 여부, 화면설계 URL 여부, 종료 건 제외 등 상세 조건 필터
- 담당자별 작업일정 산정 배지 표시

### 프로젝트 완료 및 작업 스택

- 담당자, 팀장, PM 단계별 프로젝트 완료 승인 흐름 관리
- 승인/반려 처리 및 반려 사유 기록
- 완료 처리 이력을 프로젝트 작업 스택으로 누적 관리
- 관리자 기준 작업 스택 수정 및 삭제 관리

### 프로젝트 일정

- 프로젝트별 일정 등록 및 캘린더/리스트 표시
- 관리자와 PM은 전체 프로젝트 일정 조회 가능
- 작업자는 본인이 배정된 프로젝트 일정 중심으로 조회
- 일정 등록, 수정, 완료 처리 이력 관리
- 일정 히스토리를 통해 일정 변경 내역 확인
- 일정 삭제는 관리자 권한 기준으로 제한

### 프로젝트 자료실

- 프로젝트별 자료 게시글 등록 및 조회
- 프로젝트명 또는 PJ No 기준 자료 검색
- 중요 게시글 표시
- 첨부파일 및 자료 URL 등록
- 댓글 등록 기능
- 허용 파일 형식, 파일 용량, 위험 파일 차단 등 첨부파일 보안 검증 적용

### 연차 및 휴가 관리

- 연차 신청 및 승인/반려 관리
- 휴가 일정 캘린더 및 리스트 제공
- 연차 일정 수정/삭제 기능
- 최종 승인된 연차만 휴가 일정에 반영
- 입사일과 재직기간 기준 연차 자동 계산
- 퇴사자는 자동 연차 계산 대상에서 제외
- 회원별 총 연차 및 잔여 연차 수동 조정 가능
- 연차 수정/삭제 시 잔여 연차 자동 재계산
- 연차 승인 목록 검색 필터 제공

### 회원 및 권한 관리

- 회원 등록, 수정, 재직 여부 관리
- 부서, 직급, 권한, 입사일, 퇴사일 관리
- 관리자, 팀장, 일반 사용자 권한 구분
- 부서 및 권한에 따른 메뉴 접근 제어
- 로그인 로그 및 프로젝트 변경 로그 확인

## 보안 및 권한 관리

- 관리자/팀장/PM/일반 사용자 기준 권한 분리
- URL 직접 접근 시 권한 없는 페이지 접근 제한
- 서버 API 단위 권한 검증
- 기본 관리자 비밀번호 사용 제한
- 로그인 실패 횟수 제한
- 세션 토큰 기반 로그인 유지
- 민감 데이터 암호화 저장
- CSRF 방지를 위한 요청 출처 검증
- 보안 헤더 적용
- 첨부파일 확장자, MIME 타입, 파일 크기 검증
- HTML, SVG, JavaScript, 실행파일, 압축파일 등 위험 파일 차단

## 개발 방향

AgencyFlow는 단순한 프로젝트 관리 기능 구현이 아닌, 
실제 웹에이전시 PM 업무에서 발생하는 문제를 분석하고 이를 해결하는 것을 목표로 개발하고 있습니다.

기능 추가뿐만 아니라 업무 프로세스와 사용자 경험을 지속적으로 개선하며 프로젝트를 고도화하고 있습니다.
