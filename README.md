## Overview

**AgencyFlow**는 웹에이전시 PM 업무를 수행하며 경험한  
**프로젝트 관리와 사내 연차 관리의 비효율을 개선하기 위해 개발한 업무 관리 시스템**입니다.

프로젝트 진행 현황, 일정, 고객 자료, 담당자 배정, 업무 이력 등 여러 시스템과 문서에 분산되어 있던 정보를 하나의 시스템에서 통합 관리하고, 연차 신청·승인·잔여 연차 확인까지 함께 처리할 수 있도록 설계하였습니다.

---

## Background

웹에이전시 PM으로 근무하며 프로젝트 현황 파악과 업무 인계 과정에서  
**정보가 여러 시스템과 문서에 분산되어 있어 반복 확인 작업이 발생하는 문제**를 경험했습니다.

### 기존 업무 환경

| 구분 | 관리 방식 | 발생한 문제 |
|---|---|---|
| 계약·고객 정보 | 사내 인트라넷 | 한눈에 파악하기 어렵고, 페이지 이동을 통해 확인해야 해 업무 흐름이 끊김 |
| 프로젝트 일정 | 인트라넷 일정 기능, 팀별 문서, 파트별 일정표 | 실제 업무에서는 개별 문서 중심으로 운영되어 일정 기준이 분산됨 |
| 고객 소통 | 메신저, 메모, 개별 공유 | 인수인계 시 주요 맥락을 다시 확인해야 함 |
| 연차·휴가 | 수기 관리, 메신저 상태값 | 잔여 연차와 휴가 일정을 즉시 파악하기 어려움 |

### 문제 정의

> 하나의 프로젝트 상태를 확인하기 위해 여러 시스템과 문서를 오가야 했고,  
> 진행 상황 파악, 담당자 확인, 일정 체크, 업무 인계 과정에서 반복적인 확인 작업이 발생했습니다.

### 해결 방향

AgencyFlow는 이러한 문제를 개선하기 위해 **프로젝트 정보, 담당자, 일정, 이슈, 소통내역, 자료 및 작업 이력을 <br>하나의 흐름 안에서 관리할 수 있도록 통합**했습니다.

또한 연차 신청·승인 및 휴가 일정 관리 기능을 함께 구성하여 프로젝트 운영과 사내 협업 과정에서 발생하는  
**정보 분산과 반복 확인 작업을 줄이는 것**을 목표로 구현했습니다.

## Key Features

| 구분 | 주요 기능 |
|---|---|
| **프로젝트 통합 관리** | 프로젝트 기본 정보, 계약 및 고객 정보, 마일스톤, 작업상태, 담당자 배정 관리 |
| **공정 및 작업 이력** | 담당자 → 팀장 → PM 단계별 완료 승인, 반려 사유, 작업 스택 관리 |
| **일정 관리** | 프로젝트별 일정 캘린더/리스트, 일정 히스토리, 완료 처리 이력 관리 |
| **자료 관리** | 프로젝트 자료실, 첨부파일, 자료 URL, 메신저 링크, 댓글 관리 |
| **연차 및 휴가** | 연차 신청, 승인/반려, 잔여 연차, 휴가 일정 캘린더 관리 |
| **권한 및 로그** | 관리자/팀장/PM/작업자 권한 분리, 로그인 로그, 프로젝트 변경 로그 관리 |

## Roadmap

현재 AgencyFlow는 **분산된 프로젝트 및 업무 정보를 하나의 시스템으로 통합하는 것**을 1차 목표로 구현했습니다.

향후에는 축적된 데이터를 기반으로 사용자가 직접 프로젝트를 일일이 확인하지 않아도  
**관리 필요 프로젝트와 역할별 처리 업무를 선제적으로 파악할 수 있는 운영 지원 시스템**으로 고도화할 계획입니다.

| 우선순위 | 고도화 항목 | 설명 |
|---|---|---|
| **P0** | 관리 필요 프로젝트 자동 탐지 | 납기 임박, 지연, 미배정, 승인대기 프로젝트 자동 분류 |
| **P0** | 역할별 업무관리 고도화 | PM, 팀장, 작업자별 처리 대기 항목 제공 |
| **P1** | 공정별 업무 인계 관리 | 기획/PM → 디자인 → 퍼블리싱 → 프로그램 → 검수 흐름 시각화 |
| **P1** | 변경요청 관리 | 일정·비용·공정 영향도를 포함한 변경요청 이력 관리 |
| **P2** | 리소스 현황 관리 | 작업자별 진행 프로젝트와 업무 부하 확인 |

> 상세 고도화 계획은 `docs/Roadmap.md`에서 확인할 수 있습니다.
