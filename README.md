# AgencyFlow
> Web Agency Project Management System

AgencyFlow는 웹에이전시 PM 업무를 수행하며 경험한 프로젝트 관리와 사내 연차 관리의 비효율을 개선하기 위해 개발한 프로젝트입니다.

프로젝트 진행 현황, 일정, 고객 자료, 업무 이력 등 분산되어 관리되던 정보를 하나의 시스템에서 통합 관리하고, 

연차 신청·승인·잔여 연차 확인까지 함께 처리할 수 있도록 설계하였습니다.

---

## 프로젝트 소개

웹에이전시 PM으로 근무하며 프로젝트 관리에 필요한 정보가 여러 시스템과 문서에 분산되어 있어, 프로젝트 현황을 파악하거나 업무를 인계하는 데 많은 시간이 소요되는 문제를 경험했습니다.

고객과의 메신저 소통 내역, 영업 메모, 견적서와 같은 계약·고객 정보는 인트라넷에서 확인해야 했고, 

프로젝트 일정은 별도의 일정관리 시스템, 팀별 관리 문서, 각 파트에서 개별적으로 관리하는 일정표 등으로 나뉘어 있었습니다.

이로 인해 하나의 프로젝트 상태를 확인하기 위해 여러 시스템과 문서를 오가야 했고, 진행 상황 파악, 담당자 확인, 일정 체크, 업무 인계 과정에서 반복적인 확인 작업이 발생했습니다.

또한 사내 연차 관리가 수기 방식으로 이루어져 잔여 연차를 확인하려면 인사 관리 담당자에게 직접 문의해야 하는 불편함도 있었습니다.

AgencyFlow는 이러한 비효율을 개선하기 위해 프로젝트 기본 정보, 고객 자료, 담당자 배정, 일정, 이슈, 작업 이력을 하나의 흐름 안에서 확인하고 관리할 수 있도록 설계했습니다.

아울러 연차 신청, 승인, 잔여 연차 확인까지 하나의 시스템에서 관리할 수 있도록 확장하여, 프로젝트 관리와 근태 관리 업무를 함께 개선하는 것을 목표로 구현했습니다.

## 개발 방향

AgencyFlow는 단순한 프로젝트 관리 기능 구현이 아닌,

실제 웹에이전시 PM 업무에서 발생하는 문제를 분석하고 이를 해결하는 것을 목표로 개발하고 있습니다.

기능 추가뿐만 아니라 업무 프로세스와 사용자 경험을 지속적으로 개선하며 프로젝트를 고도화하고 있습니다.
